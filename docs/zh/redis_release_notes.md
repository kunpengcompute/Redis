### 版本使用注意事项

Redis CRC16 PMULL优化需应用接入补丁并重新构建Redis，运行时自动选择计算路径，无需额外配置开关。部署前可通过`lscpu`查看处理器架构和指令集标志，确认包含`aarch64`和`pmull`；启用SHA3构建时还需确认`sha3`。Redis能够正常启动不代表已进入优化路径，应结合输入长度和运行时指令集条件判断，并在相同配置和负载下对比基线版与优化版的性能。性能提升不作为计算路径已生效的唯一依据。

### 版本说明

#### 更新说明

##### Redis网络异步优化

新增Redis大包场景零拷贝优化性能测试步骤。在2U8G的容器场景中，与未启用优化相比，启用大包场景的零拷贝优化后，SET、GET操作的性能平均提升超过5%。

##### Redis CRC16 PMULL优化

新增Redis CRC16/XMODEM优化实现，支持Linux ARM64环境下的PMULL/NEON计算路径，并根据运行环境选择可用的优化路径或标量回退路径。在特性指南所述的64B key、单核容器和集群模式GET未命中测试场景下，与未启用优化相比，启用CRC16优化后的GET吞吐量平均提升超过3%。该结果与硬件配置和测试负载相关，需在目标环境中复测。
